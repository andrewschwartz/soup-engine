# Lense by Shakespeare Bridge

Fork of [Soup Engine](https://github.com/jiijii0/soup-engine) — Canon EOS film emulation engine. GPL v2.

Lense adds:
- Canon 7D support — port to the 7D Mark II sensor
- Atomos .cube LUT export — ship your look directly to a monitor
- Grain system — analog film grain emulation
- Lens emulation — vintage glass character
- AI debayer integration — neural demosaicing pipeline
- iPhone output pipeline

Built by [Shakespeare Bridge](https://shakespearebridge.ai) — AI Filmmaking Platform.
